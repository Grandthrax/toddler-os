# Security and privacy

This is an early, single-device, loopback-only application. It is not a hosted
service or a complete parental-control product. Do not expose its HTTP port on
your network or the internet. The public desktop preview does not confine a Linux
account; see `docs/RASPBERRY-PI.md`.

For a suspected vulnerability, use the repository's private **Report a
vulnerability** option if enabled. If it is unavailable, open a minimal issue
requesting a private reporting channel; do not post exploit details or personal
data. The maintainer should enable private vulnerability reporting before the
first public release.

Never send real child databases, writing, backups, browser profiles or voice
recordings. Reproduce with temporary data and redact machine identifiers. There
is no guaranteed response time or commercial support commitment.

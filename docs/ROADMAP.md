# Roadmap

This first public preview shares the local learning apps and a supervised Pi
setup. Its scope is deliberately smaller than a prebuilt child-computer image.

Before calling it a general-purpose child appliance:

- Supply an openly licensed, reviewed British English phonics pack.
- Build a configurable Raspberry Pi kiosk installer with a dry run, backups,
  updates and rollback; test that a parent can always recover the normal desktop.
- Generalise audio recovery beyond one USB speaker and test reconnects, idle
  playback and reboot behaviour on several devices.
- Test a clean setup on additional Python versions, Pi models and Windows/Linux
  machines. Add portable browser interaction checks alongside the backend suite.
- Improve keyboard and assistive-technology access and gather usability feedback.

Possible later additions: more short branching books, parent-authored story
templates, printable books, maths missions beyond ten and multiple local profiles.
These are ideas, not features promised in this release.
